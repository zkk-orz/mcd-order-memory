## 它是什么

一个替你记住**所有人的胃口、钱包和健康**的点餐 Skill（ZCode / Claude Code / 任何支持 SKILL.md 开放规范的 AI 工具）：

- **任意格式进**：微信群接龙、群聊乱流（"老王要那个板烧 小美不吃牛肉 大家看着办"）、口头转述——不用学任何格式；
- **点名即建档**：对话里出现"人名+食物"就自动记忆，按**人 × 餐段**（午餐/下午茶/晚餐/夜宵/加班餐）隔离追踪，越用越懂每个人；
- **自动不请示**：出单自动查券/积分/会员价（含麦金卡会员价≠结算价的避坑警示）、自动统计每人卡路里、自动记账——全程不多问你一句话；
- **告知不代选**：省钱方案只呈现差异（A 原价/B 用券/C 积分换），选定权在你；真实下单有四道闸（预览→确认→执行→回报），脚本层强制 `--i-confirm` 防线。

## 能力一览（14 项）

| 域 | 能力 |
|---|---|
| 解析 | 任意格式意见解析（接龙/乱流/口头）→ 订单清单 |
| 记忆 | 点名即建档（时间戳+主体名，人×餐段三重隔离）、老单复购、月账单+省钱战绩 |
| 省钱 | 出单自动查券×积分×会员价（券后价经算价接口实算，不靠文案心算）、临期积分提示、一键领券（经确认） |
| 分账 | AA 收款卡：实付按原价比例摊+微信群收款逐人照抄清单；口头销账（"李四付了"）、欠款跨单提示（只算只记，绝不代发不代催） |
| 战报 | 本群麦门月报：单数/合计/省钱战绩/本群最爱/趣味热量换算，默认脱敏可直发点餐群 |
| 健康 | 每人每餐卡路里自动统计（160 项营养表）、按月累计与"建议"式纠偏 |

| 外送 | 地址→可送门店→到家/到公司全链路 |

## 快速开始（零配置即用，实时三选一）

**零配置即用**（无 Token、无依赖、离线可玩）：把本目录放进 skills 目录即装好——

- ZCode / Claude Code：复制到 `.zcode/skills/`（项目级）或 `~/.zcode/skills/`（用户级）
- 通用开放规范位：`.agents/skills/`（Cursor/Codex 等 40+ 客户端通用）

然后直接说人话：

```text
接龙：1.张三 双吉套餐 2.李四 麦辣不要辣 3.王五 1+1可乐，帮我点麦当劳
还是上次那单，给娃和老王来一份
李四付了，王五还没转（AA 销账）
生成本月战报
这个月家里吃麦当劳花了多少？
```

**实时增强（三选一，按你的宿主选最省事的）**：

- **宿主已配 mcd-mcp 连接器**（如 WorkBuddy 按官方指南配置过）——**无需任何额外配置**，skill 自动检测并直接原生调用：实时菜单价格、你的券/积分比价、真实下单与订单跟踪全解锁；
- 或到 [open.mcd.cn](https://open.mcd.cn) 免费申请 MCP Token，设一个环境变量：

```bash
export MCD_MCP_TOKEN=你的token
```

- 什么都没配也**照常可用**（上文的零配置全功能），只是价格标注为快照价。配置示例见 `mcp-config.example.json`。

## 数据与隐私

- 你的记忆数据（谁爱吃什么、账本）只存在你电脑的 `~/.mcd-order-memory/`——本地文件，不上传、不联网、删 skill 不丢数据；
- Token 只从环境变量读取，本仓库任何文件不含真实 Token；
- 单用户设计；营养输出不构成营养建议，餐品价格以麦当劳官方渠道实时结果为准。
