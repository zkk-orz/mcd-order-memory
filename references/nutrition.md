# 营养自主统计

## 单餐即时（用户裁决：下完订单自主统计，不询问）

订单清单**直接带每人卡路里列**（见 order-flow.md 输出模板）：
- 数据源：assets/nutrition.json（160 项营养表快照，含能量/蛋白质/脂肪/碳水/钠/钙）；
- 查不到的品项：按同类估算并标注"≈"（如新品尝试装按同类小食均值），不编精确数；
- 按人汇总：每人名下逐项求和。

## 月度累计与纠偏（告知不代选）

- `memory.py query --name 娃 --days 30` 聚合该人近 30 天卡路里/钠摄入；
- 出单时若该人当月累计已达参考值的较高比例，在清单末尾给一行**建议**：

```
📊 娃本月卡路里：这一餐后 8320 kcal，钠偏高（建议下一餐多选蔬果类，如玉米杯/蔬菜沙拉）
```

**措辞铁律**：一律"建议"措辞（多选/换/搭配），**绝不**用"超标了/超标了！"式恐吓，绝不阻止下单——呈现信息，决定权在用户。输出不构成营养建议（与参赛声明一致）。

## 数据源说明

assets/nutrition.json 由作者侧快照管线生成（scripts/snapshot.py，真实调用 list-nutrition-foods），文件头含快照日期。营养表相对静态，快照足够，**不要为营养数据调 MCP**（浪费用户等待）。
